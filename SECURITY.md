# Security Policy

ObsChain takes security seriously.

## Reporting a Vulnerability

If you discover a security vulnerability in ObsChain, please report it via private GitHub Security Advisory or email the maintainers directly. Do NOT open a public issue.

## Scope

- Denial of service attacks via malformed blockchain payloads.
- Authentication bypass or SSRF in RPC clients.
- Logic errors that misclassify unverified claims as on-chain facts.
- Memory corruption or unsafe memory access.

# ObsChain Event Model

## Overview

A `ChainEvent` represents a single detected occurrence, anomaly, or pattern on the Bitcoin network.

Events are generated by `Detector` instances analyzing incoming `Observation` streams (blocks and transactions).

## Event Fields

| Field | Type | Description |
|---|---|---|
| `id` | `Uuid` | Unique identifier |
| `event_type` | `EventType` | Type classification |
| `severity` | `EventSeverity` | `INFO`, `LOW`, `MEDIUM`, `HIGH`, `CRITICAL` |
| `confidence` | `ConfidenceLevel` | Degree of certainty (`VERIFIED_ON_CHAIN`, `HIGH`, `MODERATE`, `HEURISTIC`, `LOW`) |
| `title` | `String` | Human-readable title |
| `description` | `String` | Technical details |
| `detected_at` | `DateTime<Utc>` | Timestamp of detection |
| `block_height` | `Option<u64>` | Associated block height if confirmed |
| `block_hash` | `Option<String>` | 64-char hex block hash |
| `txid` | `Option<String>` | 64-char hex transaction ID |
| `metadata` | `serde_json::Value` | Type-specific structured metadata |

## Event Types

- `LARGE_TRANSFER`: Output values exceeding defined satoshi threshold.
- `DORMANT_UTXO_SPENT`: Spending of UTXOs created prior to a specified block height or date.
- `CONSOLIDATION`: Batching many small UTXOs into fewer destination outputs.
- `FAN_OUT`: Single UTXO distributed across many destination outputs.
- `FEE_SPIKE`: Rapid increase in fee rates.
- `RBF_REPLACEMENT`: Detection of an unconfirmed tx replaced via BIP-125 Opt-In RBF.
- `LONG_BLOCK_INTERVAL`: Duration between block timestamps exceeding normal statistical thresholds.
- `REORG_DETECTED`: Valid alternative chain tip accepted at the node level.
- `MINING_ANOMALY`: Block non-conformity, unexpected coinbase split, or difficulty deviation.
- `UNUSUAL_FEE_RATIO`: Transaction where fees paid represent an unusually large percentage of value.

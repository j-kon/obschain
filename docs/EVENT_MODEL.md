# ObsChain Event Model

## Overview

A `ChainEvent` represents a single detected occurrence, anomaly, or pattern on the Bitcoin network.

Events are generated by `Detector` instances analyzing incoming `Observation` streams (blocks, transactions, and mempool replacements).

---

## Event Fields

| Field | Type | Description |
|---|---|---|
| `id` | `Uuid` | Unique identifier (UUIDv4) |
| `event_type` | `EventType` | Categorized type of chain event |
| `severity` | `EventSeverity` | `INFO`, `LOW`, `MEDIUM`, `HIGH`, `CRITICAL` |
| `confidence` | `ConfidenceLevel` | Degree of certainty (`VERIFIED_ON_CHAIN`, `HIGH`, `MODERATE`, `HEURISTIC`, `LOW`) |
| `title` | `String` | Human-readable title |
| `description` | `String` | Technical details and metrics summary |
| `detected_at` | `DateTime<Utc>` | Timestamp of detection |
| `block_height` | `Option<u64>` | Associated block height if confirmed |
| `block_hash` | `Option<String>` | 64-char hex block hash |
| `txid` | `Option<String>` | 64-char hex transaction ID |
| `source` | `Option<ObservationSource>` | Provenance tag indicating data ingestion origin |
| `metadata` | `serde_json::Value` | Type-specific structured metrics |

## Event Types & Anomaly Detectors

### 1. `DormantCoinsMoved` (`DormantCoinDetector`)
- **Trigger**: Spending of UTXOs that have remained unspent for 5+ years (default threshold: 1,825 days, minimum value: 100,000,000 sats / 1 BTC).
- **UTXO Age Model**: Age is strictly derived from the spent historical output's confirmation timestamp (`confirmed_at`) or block height. Age is NEVER approximated from current transaction time.
- **Coin Age Destroyed (CAD)**: Exact internal representation using `u128` satoshi-days (`value_sats * age_days`) to eliminate binary floating-point rounding errors and avoid 64-bit integer overflow.
- **Objective Classifications**:
  - `Dormant`: 5+ years (1,825+ days)
  - `VeryOld`: 10+ years (3,650+ days)
  - `Ancient`: 15+ years (5,475+ days)
  - `EarlyBitcoin`: Objective historical epoch cutoff (Block height <= 100,000 or confirmed before January 1, 2011 UTC).
- **Severity Matrix**: Deterministically balances coin age and satoshi value. Dust-sized ancient outputs will never escalate to `Critical`.
- **Heuristic Caveat**: Dormant coin detection describes objective UTXO age and transaction mechanics. It NEVER attributes human ownership, intent, or "Satoshi coins" purely based on age.

### 2. `Consolidation` (`ConsolidationDetector`)
- **Trigger**: Transactions that consolidate many inputs into few outputs (default: >= 20 inputs into <= 5 outputs).
- **False-Positive Avoidance**: Explicitly excludes transactions with both high inputs and high outputs (e.g. batch payouts or CoinJoins).
- **Metrics**: Input count, output count, input/output ratio, total input sats, total output sats, fee.

#### Structured Metadata: `ConsolidationMetadata`
```json
{
  "input_count": 48,
  "output_count": 2,
  "input_output_ratio": 24.0,
  "total_input_sats": 150000000,
  "total_output_sats": 149970000,
  "fee_sats": 30000
}
```

### 3. `FanOut` (`FanOutDetector`)
- **Trigger**: Transactions creating an unusually high number of outputs (default: >= 50 outputs), characteristic of batch withdrawals or distribution services.
- **Metrics**: Output count, input count, output/input ratio, total distributed sats, median output sats, smallest output sats, largest output sats.

#### Structured Metadata: `FanOutMetadata`
```json
{
  "input_count": 2,
  "output_count": 75,
  "output_input_ratio": 37.5,
  "total_distributed_sats": 85000000,
  "total_distributed_btc": 0.85,
  "median_output_sats": 1000000,
  "smallest_output_sats": 250000,
  "largest_output_sats": 5000000
}
```

---

### 4. `ExtremeFee` (`ExtremeFeeDetector`)
- **Trigger**: Transactions paying abnormal absolute fees (default: >= 10,000,000 sats / 0.1 BTC) or abnormal fee rates (default: >= 200 sat/vB).
- **Triggers**: Distinguishes `HIGH_ABSOLUTE_FEE`, `HIGH_FEE_RATE`, and `BOTH`.
- **Safety**: Safe integer fee rate derivation with zero-vsize defense.

#### Structured Metadata: `ExtremeFeeMetadata`
```json
{
  "fee_sats": 15000000,
  "fee_btc": 0.15,
  "fee_rate_sat_vb": 350.0,
  "vsize": 428,
  "total_input_sats": 100000000,
  "total_output_sats": 85000000,
  "fee_trigger_type": "BOTH"
}
```

### 5. `TransactionReplacement` (`RbfDetector`)
- **Distinction**: BIP-125 opt-in replaceability signaling (`is_rbf`) indicates capability only. Actual transaction replacement events are emitted ONLY when a concrete replacement (`Observation::Replacement`) is verified in the mempool.
- **Neutral Reporting**: Titled strictly neutrally ("Transaction replacement observed: <txid>") without assuming double-spend or malicious intent.
- **Metrics**: Replaced TXIDs, replacement TXID, old fee, new fee, absolute fee delta, percentage fee increase, old/new fee rate.

#### Structured Metadata: `ReplacementMetadata`
```json
{
  "replaced_txids": ["9f1a..."],
  "replacement_txid": "3c8d...",
  "replaced_count": 1,
  "old_fee_sats": 12000,
  "new_fee_sats": 25000,
  "fee_delta_sats": 13000,
  "fee_increase_percent": 108.33,
  "old_fee_rate_sat_vb": 24.0,
  "new_fee_rate_sat_vb": 50.0
}
```

---

### 6. `LargeTransfer` (`LargeTransactionDetector`)
- **Trigger**: On-chain transfer value exceeding configurable satoshi threshold (default: 10,000,000,000 sats / 100 BTC).

---

### 7. `LongBlockInterval` (`LongBlockIntervalDetector`)
- **Trigger**: Elapsed wall-clock time between sequential block headers exceeding threshold (default: 1,800s / 30 mins). Non-monotonic timestamps are safely filtered.

---

## Event Deduplication & Determinism

Live feeds can replay observations during network reconnects or catch-up bursts. ObsChain prevents duplicate events via `EventDeduplicator`:
- **Deterministic Key**: Combines `EventType` with unique on-chain identifiers (e.g. `DormantCoinsMoved:tx:<txid>`, `LongBlockInterval:block:<hash>`).
- **Bounded In-Memory Cache**: Thread-safe FIFO/LRU eviction with TTL (default: 10,000 capacity, 30 min TTL).
- Deduplication runs immediately before storage and live WebSocket broadcasting.
